# PHP Management

![PHP Provider](../images/4.1.php-enable-system-or-multi.png)

NativeDev manages system PHP and multi-version PHP workflows.

## Features

- Detect existing system PHP
- Enable multi-PHP workflow
- Manage PHP-FPM versions
- Install extensions
- Manage PHP settings
