# Services and Tools

![Services](../images/3.1-services-and-tools-nginx-mariadb-postgresql.png)

NativeDev manages native development services.

Supported:

- Nginx
- MariaDB
- PostgreSQL
- Redis
- Memcached
- RabbitMQ
- Composer
- mkcert
- phpMyAdmin
- Adminer
- Mailpit
